Double-Layer Admin Security
Two independent checks must pass before anyone enters the CMS. A valid Supabase Auth session is not enough alone.
-- Layer 1: Supabase Auth (email + password) -- Layer 2: must exist in public.admins table create function is_admin() returns boolean as $$ select exists ( select 1 from admins a join auth.users u on u.email = a.email where u.id = auth.uid() ); $$ language sql security definer;

How admin access works
Two-Gate Auth
Gate 1 — Supabase Auth
Valid email + password must authenticate successfully via Supabase GoTrue service.
Gate 2 — Admins Table
The authenticated user's email must match a row in public.admins. Verified by is_admin() RLS function on every query.
Revoke without deleting
Remove a row from admins to instantly revoke CMS access — no password reset required.

🏗️ Excited to share something we've been building for the past few weeks!

We just launched a completely custom full-stack website + admin CMS system for AAC – Al Aziz Construction — Karachi's Trusted Builders.

Here's what makes this project special 👇

✅ Public Website — dynamic hero, services, portfolio, testimonials & contact — all rendered live from the database. Zero hardcoded content.

✅ Admin CMS Panel (Vue 3 + Tailwind) — the client can update every section of their website from a clean dashboard. Add projects, manage leads, publish testimonials — all without touching a single line of HTML.

✅ Supabase Backend — PostgreSQL database with Row Level Security. 8 tables, 16 RLS policies, and a custom is_admin() security function. No backend server. No Express. No Flask. Just direct Supabase integration from the frontend.

✅ Lead Management — every contact form submission flows directly into the admin panel with CSV/JSON export. No more missed inquiries.

✅ Double-layer security — Supabase Auth + admin table allowlist. Even a valid account is rejected if not explicitly approved.

The entire system is 2 HTML files + 1 SQL schema. Deployed on static hosting. Maintainable by a single developer.

🔧 Built with: Vue 3 · Tailwind CSS · Supabase · PostgreSQL · Vanilla JS

This is what's possible when you skip the framework overhead and build directly with the right primitives. 🚀
